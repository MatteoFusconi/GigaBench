# GigaBench project page

Static site served from the `gh-pages` branch. No build step.

- `index.html`, `css/`, `js/`: the page
- `assets/images.json`, `assets/previews/`: generated by `tools/make_tiles.py` on `main`
- Deep Zoom tiles: **not in this branch**. They live in the Cloudflare R2 bucket `gigabench-tiles`,
  under a version folder (`v1/`), and `TILE_BASE` at the top of `js/main.js` points there.

## Local preview

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>. The page fetches `assets/images.json`, so opening `index.html` as a
file does not work. Tiles still come from R2; the bucket's CORS rule allows `localhost:8000` and
`127.0.0.1:8000`. To work offline, link a local copy and set `TILE_BASE = "tiles"`:

```bash
ln -s /media/matteo/Storage/data/public/GigaBench_web/tiles tiles   # ignored by git
```

## Regenerate assets

From the `main` branch:

```bash
python tools/make_tiles.py --src /media/matteo/Storage/data/public/Gigadataset \
                           --out /media/matteo/Storage/data/public/GigaBench_web
```

Copy `images.json` and `previews/` into `assets/`. Upload the tiles to a **new** version folder, so
cached old tiles never mix with new ones, then update `TILE_BASE`:

```bash
rclone copy /media/matteo/Storage/data/public/GigaBench_web/tiles r2:gigabench-tiles/v2 \
  --transfers 32 --checkers 32 --progress --header-upload "Cache-Control: public, max-age=31536000"
```
