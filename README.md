# GigaBench

Official code for **Benchmarking Learnable Representations for Gigapixel Image Compression and Super-Resolution** (WACV).

Matteo Fusconi¹, Alex Costanzino¹, Pierluigi Zama Ramirez², Luigi Di Stefano¹

¹ CVLab, University of Bologna · ² Ca' Foscari University of Venice

**[Project page](https://matteofusconi.github.io/GigaBench/)**

GigaBench is a benchmark for Learnable Representations (LRs) on gigapixel images, covering image compression and super-resolution. It evaluates Implicit, Hybrid and Explicit methods, adapted to run at gigapixel scale on consumer hardware, across reconstruction quality, model size, compression time and inference time.
